# Murali Krishnan R — Personal Portfolio

A responsive, dark-themed personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- About, skills, projects, and contact sections
- Mobile navigation menu
- Scroll reveal animations using the Intersection Observer API
- Direct links to GitHub, LinkedIn, and email
- No framework or package installation required

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Clone the repository.
2. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## Customise before publishing

- Confirm the email and LinkedIn links.
- Update project links and descriptions to match the actual repositories.
- Add your resume PDF only after placing it in the project folder and linking it from the page.
- Keep project descriptions consistent with features implemented in the source code.
